# Моделирование теплообмена и трения поршневых колец ДВС

Этот репозиторий содержит Python-код (Jupyter Notebook) для численного моделирования термодинамических процессов, сил трения и характеристик масляной пленки в системе поршневых колец двигателя внутреннего сгорания (ДВС).

## 📋 Описание

Проект реализует комплексный расчет цикла работы ДВС с акцентом на:
1.  **Газодинамику:** Расчет давления и температуры в цилиндре в зависимости от угла поворота коленчатого вала (ПКВ).
2.  **Динамику колец:** Расчет осевых сил, действующих на поршневые кольца, и определение их положения в канавке (прижатие к верхней или нижней стороне).
3.  **Теплообмен:** Оценка коэффициентов теплоотдачи через торцевые поверхности колец.
4.  **Гидродинамику смазки:** Решение уравнения Рейнольдса для определения толщины масляной пленки между кольцом и гильзой цилиндра, а также расчет соответствующих коэффициентов теплопередачи через масляную пленку.

## 🛠 Используемые технологии и библиотеки

*   **Python 3.x**
*   **NumPy:** Для векторных вычислений и решения систем уравнений.
*   **Matplotlib:** Для визуализации результатов (графики давления, сил, толщин пленки).
*   **SciPy (опционально):** Может использоваться для более сложных методов интегрирования (в текущем коде используется `numpy.linalg.solve`).

## 📂 Структура проекта

Код разделен на логические блоки:

### 1. Параметры двигателя и исходные данные
Определение геометрических параметров (диаметр цилиндра, ход поршня), термодинамических констант и начальных условий для газового цикла.

### 2. Газодинамический расчет цикла
*   Расчет объема цилиндра $V(\phi)$.
*   Расчет скорости и ускорения поршня.
*   Интегрирование первого начала термодинамики для получения давления $P(\phi)$ и температуры $T(\phi)$ в цилиндре.
*   *Результат:* Графики индикаторной диаграммы и изменения температуры.

### 3. Силовой анализ поршневых колец
*   Расчет инерционных сил колец.
*   Расчет газовых сил, действующих на кольца (давление за кольцом и в канавке).
*   Определение суммарной осевой силы для каждого из трех колец.
*   Определение фаз прижатия кольца к верхней или нижней стороне канавки.

### 4. Теплообмен через торцы колец
*   Расчет коэффициента теплоотдачи $\alpha$ в зависимости от контактного давления (прижатия кольца).
*   Используется эмпирическая зависимость для контакта металл-металл и теплопроводности масла.
*   *Результат:* Графики изменения $\alpha_{up}$ и $\alpha_{down}$ для каждого кольца.

### 5. Гидродинамика масляной пленки (Уравнение Рейнольдса)
*   Моделирование профиля поверхности кольца (выпуклость).
*   Численное решение стационарного уравнения Рейнольдса с учетом граничных условий кавитации (метод Кристоферсона).
*   Итерационный поиск равновесной толщины масляной пленки $h_0$, при которой гидродинамическая подъемная сила уравновешивает сумму газовых и упругих сил.
*   Расчет эффективного коэффициента теплопередачи через масляную пленку: $\alpha = \lambda_{oil} / h_{mean}$.

## 📊 Результаты

В результате выполнения скрипта генерируются следующие графики:
1.  **Давление в цилиндре:** Индикаторная диаграмма $P-\phi$.
2.  **Осевые силы:** Силы, прижимающие кольца к канавкам, в зависимости от угла ПКВ.
3.  **Коэффициенты теплоотдачи (торцы):** $\alpha$ для верхней и нижней граней каждого кольца.
4.  **Параметры масляной пленки:**
    *   Минимальная и средняя толщина масляной пленки ($h_{min}, h_{mean}$) для каждого кольца.
    *   Коэффициент теплопередачи через масляную пленку.

Также в консоль выводятся сводные таблицы со средними значениями коэффициентов теплоотдачи и экстремальными значениями толщин пленки.

## 📝 Математическая модель

*   **Уравнение состояния:** Идеальный газ (с учетом переменного состава продуктов сгорания).
*   **Теплообмен со стенками:** Модель Воще/Эйхельберга или аналогичная эмпирическая корреляция для $\alpha_g$.
*   **Уравнение Рейнольдса:**
    $$ \frac{d}{dx} \left( h^3 \frac{dp}{dx} \right) = 6 \mu U \frac{dh}{dx} $$
    Где $h(x)$ — профиль зазора, $\mu$ — вязкость масла, $U$ — скорость скольжения.
